# 学んだテクニック集
## $-\infty$方向への切り捨て
```c++
template <typename T>
T floor(T x, T m) {
    assert(m > 0);
    T r = (x % m + m) % m;
    return (x - r) / m;
}
```

## $+\infty$方向への切り上げ
```C++
template <typename T>
T ceil(T x, T m) {
    assert(m > 0);
    if (x >= 0) {
        return (x + m - 1) / m;
    }
    return x / m;
}
```

## 空白区切りと改行
```c++
for (int i = 0; i < n; i++) {
    cout << value << " \n"[i == n - 1];
}
```

### 仕組み
文字列 ` " \n"` は、メモリ上では `[' ', '\n', '\0']` という長さ2の文字配列として扱われる。
* `i != N - 1` のとき（末尾以外）: `i == N - 1` は `0` (false) になるため、`" \n"[0]` 即ち **`' '`（半角スペース）** が出力される。
* `i == N - 1` のとき（末尾）: `i == N - 1` は `1` (true) になるため、`" \n"[1]` 即ち **`'\n'`（改行）** が出力される。

## ビット演算
```c++
// i番目のbitが1であるか
if (n & (1 << i)) {}

// i番目のbitが0であるか
if (!(n & (1 << i))) {}

// i番目のbitを1にする
n |= (1 << i);

// i番目のbitを0にする
n &= ~(1 << i);
```
* [~]はビットを反転させる演算子。(例) 0100 -> 1011

## PythonのようなマイナスインデックスをC++で表現する
```c++
std::vector<int> a(n);
// 末尾から1番目の要素
*(std::end(a) - 1);  *(a.end() - 1);
```
